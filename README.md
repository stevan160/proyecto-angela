 



## 🚀 Instalación

```bash
git clone https://github.com/stevan160/proyecto-angela.git
cd proyecto-angela
npm install
npm run dev
```

## 🔐 Variables de entorno


usa `.env` y agrega los parametros necesarios

```env
OPENAI_API_KEY=
API_URL=
```
