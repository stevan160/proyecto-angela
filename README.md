# Project Angela 🌍

Sistema de monitoreo predictivo impulsado por IA orientado a visualización de datos, análisis y asistencia inteligente.

## ✨ Features

- Dashboard moderno
- Integración con IA
- Visualización de datos
- Arquitectura escalable
- Base preparada para futuras APIs y predicción avanzada

---

## 🛠 Tecnologías

- JavaScript / TypeScript
- Node.js
- Frontend moderno
- APIs
- IA / automatización

---

## 🚀 Instalación

```bash
git clone https://github.com/stevan160/proyecto-angela.git
cd proyecto-angela
npm install
npm run dev
```

---

## 📁 Estructura Recomendada

```txt
frontend/
backend/
docs/
assets/
scripts/
```

---

## 🔐 Variables de entorno

Crea un archivo `.env` usando `.env.example`

```env
OPENAI_API_KEY=
API_URL=
```
