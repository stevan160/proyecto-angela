 



## 🚀 Instalación

```bash
git clone https://github.com/stevan160/proyecto-angela.git
cd proyecto-angela
npm install
npm run dev
```

## 🔐 Variables de entorno

```env
OPENAI_API_KEY=
API_URL=
```
